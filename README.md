# Lemon AI

`Lemon AI`는 **대화 맥락을 이어서 답하는 채팅 + 글쓰기** 콘솔 AI입니다.

## 실행 방법

```bash
python3 lemon_ai.py
```

## 주요 기능

- 자연스러운 한국어 대화 응답
- 감정 인식 기반 공감 응답(힘듦/행복 등)
- 대화 주제 추적 + 이어서 진행(`계속`)
- 글 초안 생성: `글써줘: 주제`
- 문장 다듬기: `다듬어: 문장`
- 한 줄 요약: `요약: 긴 문장`
- 도움말: `도움말`

## 예시

```text
You> 요즘 일이 너무 답답해
Lemon AI> ... 가장 힘든 한 가지를 말해주시면...

You> 계속
Lemon AI> '일' 주제로 이어갈게요. (상태/막힘/오늘 행동)

You> 글써줘: 꾸준함
Lemon AI> [주제: 꾸준함] ...
```
