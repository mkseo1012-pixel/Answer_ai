# Lemon AI

`Lemon AI`는 채팅 대화 + 글쓰기를 지원하는 콘솔 기반 AI입니다.

## 실행 방법

```bash
python3 lemon_ai.py
```

## 주요 기능

- 자연스러운 한국어 대화 응답
- 공감형 반응(힘듦/행복 등 감정 키워드 인식)
- 직전 대화 기억(간단한 단기 메모리)
- 글 초안 생성: `글써줘: 주제`
- 문장 다듬기: `다듬어: 문장`
- 한 줄 요약: `요약: 긴 문장`
- 도움말 안내: `도움말`

## 예시

```text
You> 글써줘: 꾸준함
Lemon AI> [주제: 꾸준함] ...

You> 다듬어: 오늘   기분이  좋다
Lemon AI> 다듬은 문장: 오늘 기분이 좋다.

You> 요약: 나는 오늘 계획을 세우고 집중해서 중요한 일을 끝냈다.
Lemon AI> 한 줄 요약: 나는 오늘 계획을 세우고 집중해서 중요한 일을 끝냈다
```
